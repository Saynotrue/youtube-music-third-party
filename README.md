# Music Lyrics Widget

유튜브 뮤직에서 재생 중인 곡의 **싱크 가사**를 화면 위에 띄워 주는 데스크톱 위젯입니다.
작은 바·LP 위젯으로 띄워 두거나, 전체화면으로 앨범 아트와 함께 가사를 크게 볼 수 있습니다.

- 재생 중인 곡에 맞춰 가사가 한 줄씩 넘어가는 싱크 가사
- 커버 영상도 원곡을 찾아 가사 표시 (lrclib → Apple Music·NetEase·QQ Music 등 → 유튜브 자막 순으로 검색)
- 외국어 가사를 한국어로 번역 (구글 번역 + 선택: NVIDIA 무료 AI로 곡 전체 문맥을 살린 번역)
- 음악에 맞춰 움직이는 이퀄라이저, 앨범 아트 색에 맞춘 배경
- 위젯에서 재생/일시정지, 이전/다음 곡, 구간 이동, 볼륨 조절

> 유튜브 뮤직은 **크롬 계열 브라우저**(Chrome, Edge, Whale 등)에서 재생하고, 브라우저의 **Tampermonkey 스크립트**가 재생 정보를 위젯으로 보내는 구조입니다. 위젯 앱과 Tampermonkey 스크립트를 **둘 다** 설치해야 합니다.

## 설치

### 1. 위젯 앱 설치

[Releases](https://github.com/Saynotrue/youtube-music-third-party/releases) 페이지에서 운영체제에 맞는 파일을 받습니다.

| 운영체제 | 파일 |
|---|---|
| macOS (Apple Silicon: M1 이상) | `Music Lyrics Widget-<버전>-arm64.dmg` |
| Windows (설치형) | `Music Lyrics Widget Setup <버전>.exe` |
| Windows (설치 없이 실행) | `Music Lyrics Widget <버전>.exe` |

#### macOS

1. 받은 `.dmg` 파일을 엽니다.
2. **Music Lyrics Widget** 아이콘을 **Applications(응용 프로그램)** 폴더로 끌어다 놓습니다.
3. 응용 프로그램 폴더에서 앱을 실행합니다.

처음 실행할 때 아래와 같은 경고가 뜰 수 있습니다. 앱이 Apple 공증을 받지 않았기 때문이며, 다음 방법으로 열 수 있습니다.

- **"확인되지 않은 개발자"라서 열 수 없다는 경고**
  **시스템 설정 → 개인정보 보호 및 보안**으로 가서, 아래쪽의 "Music Lyrics Widget"이 차단되었다는 안내 옆 **그래도 열기**를 누릅니다.
- **"손상되었기 때문에 열 수 없습니다" 경고**
  터미널에서 아래 명령을 한 번 실행한 뒤 다시 엽니다.
  ```bash
  xattr -cr "/Applications/Music Lyrics Widget.app"
  ```

실행하면 화면 아래에 가사 바가 뜨고, 메뉴 막대에 트레이 아이콘이 생깁니다.

#### Windows

1. **설치형**: `Music Lyrics Widget Setup <버전>.exe`를 실행해 설치합니다.
   **설치 없이 실행**: `Music Lyrics Widget <버전>.exe`를 원하는 폴더에 두고 바로 실행합니다.
2. **"Windows의 PC 보호" (SmartScreen)** 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 코드 서명을 하지 않은 앱이라 뜨는 안내입니다.
3. 혹시 **Windows 방화벽** 허용 창이 뜨면 **허용**을 눌러도 됩니다. 위젯은 이 컴퓨터 안(127.0.0.1)에서만 브라우저와 통신하므로 외부 네트워크에는 열리지 않습니다.

실행하면 화면 아래에 가사 바가 뜨고, 작업 표시줄 오른쪽 알림 영역에 트레이 아이콘이 생깁니다.

### 2. Tampermonkey 스크립트 설치

1. 크롬 계열 브라우저에 [Tampermonkey](https://www.tampermonkey.net/) 확장 프로그램을 설치합니다.
2. **Chrome / Edge만 해당**: 브라우저의 확장 프로그램 관리 화면(`chrome://extensions`, `edge://extensions`)에서
   - Tampermonkey **세부정보 → 사용자 스크립트 허용**을 켭니다. (메뉴가 없으면 오른쪽 위 **개발자 모드**를 켭니다.)
3. 브라우저 툴바의 Tampermonkey 아이콘 → **새 스크립트 만들기**를 누릅니다.
4. 편집기의 기본 내용을 모두 지우고, 이 저장소의 [`tampermonkey.js`](tampermonkey.js) 내용을 **전부** 복사해 붙여 넣은 뒤 저장합니다(⌘S / Ctrl+S).
5. [유튜브 뮤직](https://music.youtube.com)을 열거나 새로고침하고 곡을 재생합니다.

위젯에 곡 제목과 가사가 나타나면 설치가 끝난 것입니다.

> 새 버전이 나오면 위젯 앱과 함께 Tampermonkey 스크립트도 최신 `tampermonkey.js`로 바꿔 주세요. 스크립트 맨 위 `@version`으로 버전을 확인할 수 있습니다.

## 사용법

### 화면 모드

| 모드 | 설명 | 여는 방법 |
|---|---|---|
| **Bar** (기본) | 화면 아래에 뜨는 가로 바. 현재 가사와 이퀄라이저 표시 | 설정 → 위젯 스타일 → Bar |
| **LP** | 레코드판 모양의 작은 위젯 | 설정 → 위젯 스타일 → LP |
| **전체화면** | 앨범 아트, 곡 정보, 가사를 크게 표시 | 바의 전체화면 버튼 또는 위젯 빈 곳 더블클릭 |

- 바와 LP 위젯은 끌어서 원하는 위치로 옮길 수 있고, 항상 다른 창 위에 떠 있습니다.
- 전체화면에서 나오려면 **Esc**를 누르거나 빈 곳을 더블클릭합니다.

### 트레이 아이콘 메뉴

| 메뉴 | 동작 |
|---|---|
| 설정 | 설정 창 열기 |
| 숨기기 / 보이기 | 위젯 숨기기·다시 보이기 (단축키 ⌘⇧Space / Ctrl+Shift+Space, 설정에서 켠 경우) |
| 종료 | 앱 종료 |

### 전체화면

**버튼** (마우스를 3초 동안 움직이지 않으면 버튼과 커서가 숨겨지고, 움직이면 다시 나타납니다)

| 위치 | 버튼 | 동작 |
|---|---|---|
| 오른쪽 위 | 번역 (文가) | 가사 아래에 한국어 번역 표시 켜기/끄기 |
| 오른쪽 아래 | 가사 | 가사 창 보이기/숨기기 (숨기면 곡 정보가 화면 가운데로) |
| 오른쪽 아래 | 소리 | 클릭하면 음소거, 마우스를 올리면 볼륨 슬라이더 |

**마우스**

- **가사 줄 클릭**: 그 가사 위치로 이동
- **진행 바 클릭/끌기**: 원하는 시간으로 이동 (마우스를 올리면 시간 표시)
- 재생/이전/다음 버튼: 곡 정보 아래

**키보드**

| 키 | 동작 |
|---|---|
| Space | 재생 / 일시정지 |
| ← / → | 5초 뒤로 / 앞으로 |
| ↑ / ↓ | 가사 싱크 +50ms / −50ms (가사가 늦게 나오면 ↑, 빨리 나오면 ↓) |
| Esc | 전체화면 나가기 |

일시정지와 구간 이동은 소리가 부드럽게 줄었다가 다시 커지도록 처리됩니다.

### 가사 번역

전체화면 오른쪽 위 **번역 버튼**을 켜면 외국어 가사 아래에 한국어 번역이 붙습니다.

1. **구글 번역**: 버튼을 누르면 1초 안에 줄마다 번역이 붙습니다. 별도 설정이 필요 없습니다.
2. **AI 문맥 번역** (선택): NVIDIA API 키를 설정하면, 곡 전체의 흐름과 말투를 맞춘 번역이 준비되는 대로 구글 번역을 자연스럽게 대체합니다. 번역 버튼의 **가** 옆에 **AI** 표시가 붙으면 AI 번역이 적용된 상태입니다.

- 무료 AI 서버는 대기 시간이 있어 한 곡에 1~2분 정도 걸립니다. 대기열의 **다음 곡은 미리 번역**해 두므로, 이어서 들으면 곡이 시작될 때 바로 AI 번역이 나옵니다.
- 한국어 가사는 번역하지 않습니다.
- 가사에 번역이 이미 들어 있는 곡(원문 / 발음 / 번역 형식)은 그 번역을 그대로 씁니다.

#### NVIDIA API 키 발급과 설정 (무료)

1. [build.nvidia.com](https://build.nvidia.com/)에 가입하고 로그인합니다.
2. 오른쪽 위 프로필 → **API Keys** → **Generate API Key**를 눌러 키를 만듭니다.
   키(`nvapi-…`)는 **만들 때 한 번만** 보이므로 바로 복사합니다.
3. 위젯의 트레이 아이콘 → **설정** → **AI 가사 번역 · NVIDIA API 키**에 붙여 넣고 **저장**을 누릅니다.
4. 상태가 `사용 중 · nvapi-••••…`로 바뀌면 완료입니다.

키는 이 컴퓨터에만 암호화해서 저장되며(macOS 키체인 / Windows DPAPI), 다른 곳으로 보내지 않습니다. **삭제**를 누르면 지워집니다.
키를 다른 사람과 공유하거나 화면 캡처에 노출하지 마세요.

### 설정

트레이 아이콘 → **설정**

| 항목 | 설명 |
|---|---|
| 투명도 | 바 위젯의 투명도 |
| 자동 페이드 | 마우스가 위젯 위에 없으면 바를 흐리게 |
| 위젯 스타일 | Bar / LP |
| 트레이 아이콘 | 음표 / 스펙트럼 모양 |
| 가사 싱크 조절 | 가사가 나오는 시점을 100ms 단위로 조절 |
| AI 가사 번역 · NVIDIA API 키 | AI 문맥 번역용 키 저장/삭제 |
| 항상 위에 표시 | 위젯을 다른 창 위에 고정 |
| 글로벌 단축키 | ⌘⇧Space / Ctrl+Shift+Space로 위젯 보이기/숨기기 |

## 문제 해결

**위젯에 아무것도 나오지 않아요**
- 위젯 앱이 실행 중인지, Tampermonkey 스크립트가 켜져 있는지 확인합니다.
- 유튜브 뮤직 탭을 새로고침합니다.
- 다른 프로그램이 8888, 8889 포트를 쓰고 있으면 연결되지 않습니다.

**이퀄라이저가 움직이지 않아요**
- 브라우저 정책상, 유튜브 뮤직 페이지를 한 번 클릭해야 소리 분석이 시작됩니다.

**"가사 없음"이 떠요**
- 모든 가사 제공처에 싱크 가사가 없는 곡입니다. 가사 서버가 일시적으로 바쁘면 자동으로 몇 번 다시 찾습니다.

**가사가 소리보다 빠르거나 늦어요**
- 전체화면에서 ↑ / ↓ 키, 또는 설정 → 가사 싱크 조절로 맞춥니다. 커버곡은 원곡과 전주 길이가 달라 조절이 필요할 수 있습니다.

**AI 번역이 붙지 않아요**
- 설정에서 NVIDIA API 키 상태가 `사용 중`인지 확인합니다.
- 무료 서버가 바쁘면 실패할 수 있으며, 이때는 구글 번역이 그대로 남습니다.

## 개인정보

- 가사 검색을 위해 곡 제목과 가수 이름을 가사 제공처(lrclib 등)에 보냅니다.
- 번역을 켜면 가사 내용을 구글 번역으로, AI 번역을 쓰면 NVIDIA로 보냅니다.
- 위젯과 브라우저 사이의 통신은 이 컴퓨터 안(127.0.0.1)에서만 이뤄집니다.

## 개발

```bash
npm install
npm start          # 개발 모드로 실행
npm run build      # 배포 파일 만들기 → dist/
```

- macOS에서 빌드하면 `.dmg`, Windows에서 빌드하면 설치형·포터블 `.exe`가 `dist/`에 만들어집니다.
- 구성
  - `main.js`: Electron 메인 프로세스 (창, 트레이, 설정 저장)
  - `server.js`: 가사 검색·번역 서버 (HTTP 8888, WebSocket 8889)
  - `renderer/`: 위젯 화면
  - `tampermonkey.js`: 유튜브 뮤직 페이지에서 재생 정보·오디오 분석 데이터를 보내는 사용자 스크립트
  - `vendor/syncanto/`: 추가 가사 제공처 (Apple Music, NetEase, QQ Music, KuGou 등)
